# Sorein Copywriting Conversion

## Purpose
Use this skill for all Sorein ecommerce copy, product copy, section headlines, CTAs, SEO copy, ads, FAQs, and conversion messaging.

## When to use
Use this skill for:
- Homepage copy
- Product page copy
- Product builder copy
- Collection copy
- FAQ copy
- Trust blocks
- Delivery/warranty text
- Technical explanation
- Ad landing pages
- SEO descriptions
- Email/SMS copy

## Voice
Sorein copy should sound:
- Premium
- Clear
- Confident
- Technical
- Calm
- Trustworthy
- Scandinavian
- Modern
- Benefit-led

Avoid:
- Cheap sales hype
- Too many exclamation marks
- Fake urgency
- Unverified claims
- Generic AI filler
- Overcomplicated engineering language
- Meaningless phrases like "revolutionary solution"

## Messaging pillars
Use these themes:
- Energy independence
- Home backup confidence
- Off-grid freedom
- Clean portable power
- Expandable modular systems
- LiFePO4 safety and cycle life
- Solar-ready charging
- Built for real-world emergencies
- Premium design
- Swedish/EU trust

## Headline formulas
Use:
- Power your [home/cabin/RV] when [problem] happens.
- Backup energy built for [specific use case].
- Clean power for [audience/use case].
- Expandable energy for [scenario].
- Stay powered through [event/problem].
- Build the system your life actually needs.

Examples:
- Power your home when the grid stops.
- Backup energy for cabins, homes, and off-grid life.
- Build your own expandable power station.
- Solar-ready power for serious independence.
- Clean backup power, ready when you need it.

## CTA rules
Good CTAs:
- Build your system
- Add to cart
- Choose your setup
- Compare systems
- See what it powers
- Start your backup setup
- Configure A6 Pro
- View technical specs

Avoid:
- Click here
- Submit
- Learn more as the only CTA
- Buy now everywhere without context

## Product explanation style
Explain technical specs in plain language:
- Wh/kWh = how much energy is stored
- W = how much power it can deliver at once
- LiFePO4 = safer, long-cycle battery chemistry
- Solar input = how fast it can recharge from panels
- UPS = backup switching for power interruptions

## FAQ style
FAQs must answer real buyer objections:
- How long can it power my devices?
- Can I use solar panels?
- Is it safe indoors?
- How long does delivery take?
- What is included?
- Can I expand it later?
- What warranty/support do I get?
- Can it power a refrigerator?
- Can it support a cabin or RV?

## Final copy check
Before finalizing:
- Is the copy clear?
- Is it specific to energy products?
- Is it premium?
- Is it believable?
- Does it help the buyer choose?
- Does it support conversion?
- Does it avoid fake claims?
