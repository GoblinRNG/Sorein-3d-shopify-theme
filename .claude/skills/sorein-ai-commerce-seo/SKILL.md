# Sorein AI Commerce SEO

## Purpose
Use this skill for SEO, AI-shopping readiness, structured data, product page content, collection architecture, and search-intent strategy for Sorein.

## When to use
Use this skill for:
- Product pages
- Collection pages
- Homepage SEO
- FAQ sections
- Product schema
- Comparison pages
- Blog/guide pages
- AI commerce readiness
- Google Merchant Center preparation
- Swedish/EU market search intent

## SEO direction
Sorein should rank for intent around:
- portable power station
- solar generator
- home backup power
- battery backup for home
- off-grid power system
- cabin power system
- RV power station
- emergency power station
- LiFePO4 power station
- solar panel generator
- power station Sweden
- backup power Sweden
- portable battery generator
- expandable power station

## Collection strategy
Create collections around customer intent:
- Home Backup
- Off-Grid Cabin
- RV & Camping
- Solar Generators
- Portable Power Stations
- Expandable Battery Systems
- Emergency Power
- Solar Panels
- Accessories

Each collection should include:
- Clear H1
- Short intro
- Product grid
- Buying guide content
- Use cases
- FAQ
- Internal links
- Comparison/help section

## Product page content
Each product page should answer:
- What is it?
- Who is it for?
- What can it power?
- How much capacity?
- What battery chemistry?
- How does solar charging work?
- Can it expand?
- What is included?
- How long is delivery?
- What warranty/support exists?
- Why choose this over alternatives?

## Structured data
When appropriate, include:
- Product schema
- Offer data
- Availability
- Price currency
- Aggregate rating only if real
- FAQ schema only for visible FAQs
- Breadcrumb schema
- Organization schema
- WebSite schema

Never fake:
- Reviews
- Ratings
- Awards
- Certifications
- Stock data
- Delivery guarantees

## AI commerce readiness
Product data should be:
- Clean
- Structured
- Specific
- Human-readable
- Machine-readable
- Consistent across PDP, schema, and merchant feed

Use clear attributes:
- Capacity Wh/kWh
- Output W
- Battery chemistry
- Cycle life
- Solar input
- AC charging speed
- Weight
- Dimensions
- Included accessories
- Warranty
- Delivery estimate

## Copywriting style
Write SEO copy that is:
- Clear
- Premium
- Technical but understandable
- Benefit-led
- Not keyword-stuffed
- Useful for real buyers

Avoid:
- Generic AI paragraphs
- Overpromising
- Fake claims
- Thin content
- Repeating the same keyword unnaturally
