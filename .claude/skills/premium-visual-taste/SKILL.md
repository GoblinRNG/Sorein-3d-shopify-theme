# Premium Visual Taste

## Purpose
Use this skill to judge and improve the visual quality of Sorein UI. This skill prevents generic AI-looking design and forces high-end taste.

## When to use
Use this skill for:
- Visual design
- UI review
- Homepage sections
- Product cards
- Hero sections
- Checkout/cart UI
- Product builder UI
- Typography
- Spacing
- Color palette
- Component refinement
- Before/after upgrades

## Taste rules
A premium Sorein design must have:
- Clear hierarchy
- Intentional spacing
- High-quality alignment
- Calm color palette
- Strong product focus
- No clutter
- No random decoration
- Consistent border radius
- Consistent shadows
- Consistent grid
- Strong mobile design
- Real ecommerce clarity

## Visual quality checklist
Ask:
- Would this look expensive to a 45-year-old homeowner?
- Would this convince someone to spend thousands of SEK?
- Does it feel like a serious energy-tech brand?
- Does the product remain the hero?
- Is the CTA obvious?
- Are specs beautiful and readable?
- Does the mobile version feel native and polished?
- Is every visual effect justified?
- Is there enough whitespace?
- Does anything look like a template?

## Spacing system
Use consistent spacing:
- 4px micro spacing
- 8px compact spacing
- 12px small inner spacing
- 16px card spacing
- 24px section/card spacing
- 32px grouped spacing
- 48–80px section spacing
- Larger spacing for hero/major sections

## Card design
Premium cards should use:
- 16–28px border radius
- Subtle border
- Soft shadow
- High-quality padding
- Clear title
- Clear body
- Minimal icon use
- Hover state
- Focus state

Avoid:
- Thick harsh borders
- Heavy dark shadows
- Inconsistent radii
- Too many badges
- Random emoji
- Oversaturated backgrounds

## Futuristic but premium
Use futuristic details carefully:
- Fine grid lines
- Subtle glow
- Technical labels
- Soft glass panels
- Blueprint marks
- Energy lines
- Animated capacity bars

Do not use:
- Cyberpunk chaos
- Neon overload
- Spinning objects everywhere
- Fake hologram gimmicks
- Sci-fi UI that reduces readability

## Final taste pass
Before final answer, improve:
- Typography scale
- Button hierarchy
- CTA placement
- Visual rhythm
- Product image quality
- Section spacing
- Mobile stacking
- Trust positioning
- Color consistency
