# Ecommerce CRO UX

## Purpose
Use this skill to make Sorein pages sell better. Every design decision must improve trust, clarity, product understanding, or conversion.

## When to use
Use this skill for:
- Homepage strategy
- Product page structure
- Product builder UX
- Collection pages
- Cart drawer/page
- Checkout path preparation
- Landing pages
- Trust sections
- Financing/payment sections
- Comparison sections
- Mobile buying UX
- Conversion reviews

## Core ecommerce principle
A beautiful page is not enough. The customer must quickly understand:
1. What is this product?
2. Is it right for my home/cabin/RV/emergency use?
3. What can it power?
4. How long will it last?
5. What is included?
6. How much does it cost?
7. How fast is delivery?
8. Can I trust the brand?
9. What happens after I buy?
10. What should I click next?

## Sorein customer types
Design for:
- Homeowners wanting backup power
- Cabin owners wanting off-grid power
- RV/camping users wanting portable power
- Emergency-preparedness buyers
- Solar users
- Technical buyers comparing specs
- Older buyers needing clarity and trust
- Younger buyers wanting premium tech

## Product page rules
A Sorein product page should include:
- Hero with product image, product name, key benefit, price, CTA
- Delivery and payment information near CTA
- Trust row: warranty, support, secure payment, delivery
- What it powers section
- Capacity explanation
- Solar charging explanation
- Battery chemistry / LiFePO4 trust block
- Expandable system explanation
- Technical specs
- Use cases
- Comparison table
- FAQ
- Reviews/testimonials placeholder if real reviews are unavailable
- Sticky add-to-cart on mobile

## CTA rules
Use clear CTA text:
- Add to cart
- Build your system
- Choose configuration
- Compare systems
- See what it powers
- Get backup power

Avoid weak CTA text:
- Learn more only
- Submit
- Click here
- Discover magic

## Cart rules
Cart must:
- Show product images
- Show selected configuration clearly
- Show shipping/delivery messaging
- Show payment/financing messaging
- Show trust/support
- Make checkout obvious
- Avoid visual clutter

## Mobile-first rules
Most ecommerce traffic is mobile. Mobile must be:
- Fast
- Clean
- Thumb-friendly
- Sticky CTA where useful
- Clear product image
- Easy quantity controls
- No tiny text
- No hidden price
- No overloaded animation
- No horizontal scroll

## Trust architecture
Use trust elements near buying decisions:
- Secure checkout
- Delivery estimate
- Warranty
- Support
- EU/Sweden relevant messaging
- Battery safety
- LiFePO4 cycle life
- Real technical specs
- Clear return/shipping info

## Conversion review checklist
Before finalizing:
- Is the main CTA visible above the fold?
- Is the product value clear in 5 seconds?
- Is price visible?
- Is delivery visible?
- Is the product image premium?
- Does the page answer objections?
- Does mobile make buying easy?
- Does the design feel trustworthy for expensive products?
- Are technical specs easy to understand?
- Are there no distracting animations near the CTA?
